====================================================
    币安合约交易软件 v1.0  —  使用说明
====================================================

一、安装环境
----------------------------------------------------
1. 安装 Python 3.10 或更高版本
   下载地址: https://www.python.org/downloads/
   安装时勾选 "Add Python to PATH"

2. 安装依赖（只需执行一次）
   Windows: 双击 install.bat
   或手动运行: pip install -r requirements.txt


二、获取币安 API Key
----------------------------------------------------
1. 登录 币安官网 binance.com
2. 右上角头像 → API 管理
3. 创建新 API Key（选择"系统生成"）
4. 开启权限: 勾选 "启用合约"（不要勾选提现）
5. 绑定 IP（可选，建议绑定以提高安全性）
6. 保存 API Key 和 Secret（Secret 只显示一次！）

   测试网 API Key（免费模拟交易）:
   https://testnet.binancefuture.com/


三、运行软件
----------------------------------------------------
双击 run.bat
或在命令行中执行: python main.py


四、界面说明
----------------------------------------------------
[连接区]   输入 API Key 和 Secret，点击"连接"
            勾选"测试网"时使用模拟账户（推荐先用测试网）

[账户总览] 显示可用余额、钱包余额、未实现盈亏
            每 15 秒自动刷新

[手动下单]
  - 交易对: 输入如 BTCUSDT、ETHUSDT 等
  - 订单类型: MARKET（立即成交）/ LIMIT（挂单）
  - 杠杆倍数: 1–125 倍（风险随杠杆增大）
  - 数量: 合约张数（BTC 最小 0.001）
  - 限价: 仅 LIMIT 订单需要填写

[当前持仓] 显示所有合约持仓，点击行后可平仓

[操作日志] 记录所有操作和错误信息


五、风险提示
----------------------------------------------------
! 合约交易存在极高风险，可能损失全部本金
! 请先使用测试网熟悉操作再使用真实资金
! 建议设置止损，控制仓位大小
! 不要将 API Secret 泄露给任何人


六、常见问题
----------------------------------------------------
Q: 连接失败 "Invalid API-key"
A: 检查 API Key 是否复制完整，注意不要有空格

Q: 下单失败 "Margin is insufficient"
A: 账户余额不足，请充值或减少数量/杠杆

Q: 下单失败 "Quantity less than min"
A: 数量太小，BTC 最小 0.001 张

Q: 测试网连接失败
A: 需要单独在 testnet.binancefuture.com 注册并生成测试网 API Key
