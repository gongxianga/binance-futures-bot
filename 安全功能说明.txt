📋 新增安全特性
═══════════════════════════════════════════════

1. 【用户名/密码登录】
   ✓ 所有功能需要登录后才能使用
   ✓ 密码采用 Werkzeug 加密存储
   ✓ Session 会话管理，安全可靠

2. 【验证码防护】
   ✓ 登录时需输入图形验证码
   ✓ 验证码5分钟自动过期
   ✓ 有效防止自动化暴力破解

3. 【登录失败限制】
   ✓ 同一IP连续失败5次后锁定
   ✓ 锁定时间：5分钟 (300秒)
   ✓ 有效防止密码暴力破解

4. 【API密钥加密】
   ✓ 币安API Key和Secret加密存储
   ✓ 使用 Fernet 对称加密算法
   ✓ 密钥文件独立保存 (secret.key)
   ✓ 前端不显示完整密钥

5. 【IP白名单】
   ✓ 可限制特定IP地址登录
   ✓ 支持配置多个IP
   ✓ 白名单为空时允许所有IP

6. 【Session安全】
   ✓ 随机生成 Secret Key
   ✓ 每个会话独立验证
   ✓ 自动登出保护

🔧 高级配置
═══════════════════════════════════════════════

一、修改密码
编辑 users.json 文件，或通过 Python 生成新密码：

from werkzeug.security import generate_password_hash
print(generate_password_hash('新密码'))

二、配置IP白名单
编辑 users.json 文件，在 ip_whitelist 数组中添加IP：

{
  "1": {
    "username": "admin",
    "password_hash": "...",
    "ip_whitelist": ["192.168.1.100", "10.0.0.5"]
  }
}

留空表示允许所有IP：
  "ip_whitelist": []

三、添加新用户
在 users.json 中添加新条目：

{
  "2": {
    "username": "user2",
    "password_hash": "pbkdf2:sha256:...",
    "ip_whitelist": []
  }
}

四、修改登录限制
编辑 app.py 中的参数：

rate_limiter = LoginRateLimiter(
    max_attempts=5,      # 最大尝试次数
    lockout_duration=300 # 锁定时长（秒）
)

🐛 故障排除
═══════════════════════════════════════════════

Q: 忘记密码怎么办？
A: 删除 users.json 文件，重启程序会重新创建默认账户

Q: 被锁定怎么办？
A: 等待5分钟后自动解锁，或重启程序

Q: 验证码显示不出来？
A: 检查是否安装 Pillow 库：pip install pillow

Q: IP白名单不生效？
A: 检查 users.json 格式是否正确，IP地址是否准确
